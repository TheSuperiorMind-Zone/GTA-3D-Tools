Danica EXE build automation

The Windows GitHub Actions workflow is in .github/workflows/build-danica-exe.yml.
It extracts the original Danica (Tools).rar from this repository, identifies a supported project entry point, and builds a single-file Windows executable when the archive format supports automated compilation.
The workflow uploads a build report and file inventory even if compilation fails.

This helper file is on the isolated build-danica-exe branch; main is unchanged.
